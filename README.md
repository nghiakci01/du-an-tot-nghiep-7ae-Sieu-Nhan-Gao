# Dự án Tốt nghiệp - Siêu Nhân Gao

Dự án website thương mại điện tử Elite, xây dựng trên nền tảng Laravel.

## 🚀 Cửa sổ nhanh (Quick Start)

Để bắt đầu chạy dự án sau khi bạn mới pull code về, vui lòng tham khảo file hướng dẫn chi tiết:

👉 **[HƯỚNG DẪN CHẠY DỰ ÁN (PULL_GUIDE.md)](file:///c:/laragon/www/elite/PULL_GUIDE.md)**

### Lệnh nhanh:
```bash
composer setup
composer dev
```

## Giới thiệu về dự án
Website được thiết kế với các tính năng:
- Trang chủ tích hợp Theme Reid.
- Hệ thống quản lý sản phẩm, danh mục.
- Chatbot hỗ trợ AI tích hợp OpenAI.
- Quản lý giỏ hàng và thanh toán.

## Yêu cầu hệ thống
- PHP ^8.2
- MySQL / MariaDB
- Node.js & NPM
- Laragon (Khuyên dùng trên Windows)

## Giấy phép
Hệ thống được phát triển phục vụ mục đích học tập và tốt nghiệp.
